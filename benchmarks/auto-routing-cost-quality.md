# Auto 路由质量成本报告

实验日期：2026-07-28；公开默认档确认：2026-08-08

## 结论

Auto 采用确定性的检索感知路由，不调用额外分类模型。公开默认 `RETRIEVAL_AWARE_50` 在 200 题困难集回放中选择 Fast 107 题、Deep 93 题，研究 Token 减少 `50.16%`、平均研究时间减少 `50.04%`，Recall@5 从全 Deep 的 `0.9633` 降到 `0.8667`。

这是用户明确选择的成本优先默认档。系统同时保留质量优先的 `RETRIEVAL_AWARE_28`：研究 Token 减少 `27.58%`，Recall@5 为 `0.9367`。

双方都跳过最终答案生成。本报告中的 Token 与时间只代表检索 / 研究阶段，不能解释为端到端回答账单或用户等待时间同比下降。

## 数据和历史 Artifact

- 数据：中文企业技术知识库 v1 的 200 题困难集。
- Fast Artifact：`9da94cf0-7e48-4f44-b216-ccd032411bfe`，原问题 Keyword Top30 + Semantic Top30 + RRF Top40，200/200。
- Deep Artifact：4 批各 50 题的成功研究结果，按 Benchmark Case ID 与 Fast 配对。
- Router 新增生成式模型调用：0。
- Deep 基线研究 Token：3,269,084；平均耗时 46.850 秒。

Fast Artifact 在 Rerank、上下文装包和最终回答前结束，生成式研究 Token 记为 0。Deep Artifact 包含问题分析、父块 Deep Read 和 Evidence Judge。这个差异正是路由要避免的研究成本，但也意味着端到端 Fast 仍会产生回答生成 Token。

## 可部署方案

检索感知路由先执行：

```text
原问题
  -> Keyword Top30 + Semantic Top30
  -> RRF Top40
  -> 检查 Top5 文档标题
  -> Fast：复用预检索结果
  -> Deep：预检索耗时 + Deep 研究耗时
```

时间统计已经把 Deep 分支的预检索开销计入，没有隐藏路由成本。规则只读取当前问题和实时检索结果，不读取期望答案、期望文档、Case ID 或评测题型。

## 默认档规则

`RETRIEVAL_AWARE_50`：

```text
已有高置信 Fast 信号
OR 多 Goal 且 titleHitCount >= 1
OR 分阶段且 titleHitCount >= 2
=> Fast
其余 => Deep
```

`RETRIEVAL_AWARE_28` 把多 Goal 阈值提高到 2，因而保留更多边界问题给 Deep。预检索异常、超时、空输入或不确定问题固定 Fail Deep；明确跨文档、综合、比较、冲突和“诊断 + 修复”信号不会被标题命中降级为 Fast。

## 默认档分来源

| 来源 | Recall@5 | Token 节省 |
| --- | ---: | ---: |
| Ant Design | 0.8567 | 52.44% |
| Apache Doris | 0.8367 | 71.02% |
| Kubernetes | 0.9167 | 51.73% |
| openEuler | 0.8567 | 26.51% |

默认档整体 Recall@5 为 0.8667，但 Apache Doris 单来源为 0.8367，说明路由阈值存在领域差异。新知识领域应先 Shadow 观测，不应直接假设当前标题命中规则仍然成立。

## 为什么不增加本地分类模型

实验使用问题结构、技术锚点、Top5 RRF 分数、标题命中和问题 / 标题字符相似度训练 Ridge、Extra Trees、Random Forest、Gradient Boosting 与 Histogram GBDT，并按四个来源留一交叉验证。约 50% Token 点的最好模型 Recall@5 为 0.8517，低于确定性规则的 0.8667。

200 题也不足以承担新模型的训练、版本、漂移和监控成本，所以当前选择更透明的确定性规则。

## 运行配置

```bash
# 默认成本优先
RAG_AUTO_ROUTER_PROFILE=RETRIEVAL_AWARE_50

# 质量优先
RAG_AUTO_ROUTER_PROFILE=RETRIEVAL_AWARE_28
```

显式 Fast / Deep 始终覆盖 Auto。路由事件记录 Profile、`titleHitCount`、信号、最终模式、候选数、预检索耗时和 Top5 文档摘要。

## 限制

1. 结果来自同一 200 题的 Artifact 回放，不是在线 A/B 流量。
2. Fast 与 Deep 的研究契约不同，不能把 Fast AEC 机械记为零后比较。
3. 最终回答 Token、生成延迟、用户追问率和人工满意度不在本实验中。
4. 默认档是明确的成本取舍，不是“只降 3% 指标就省 50%”的泛化承诺；Recall@5 的绝对下降为 0.0967。
5. 新模型、新领域或 Chunk Policy 变化后需要重新校准。

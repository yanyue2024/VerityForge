# Deep RAG 最终链路：200 题检索与证据验收

评测日期：2026-08-06 至 2026-08-07

## 结论

当前 Deep 的 Goal 批量父块策略在中文企业技术知识库 v1 的 200 题困难集上最终完成 200/200：Recall@5 `0.9758`、AEC `0.9191`、RCC `0.9373`。相对同集 GPT-5.5 ReAct 历史基线，Recall@5 提高 `0.1208`，P50 下降 `44.9%`，包含失败尝试的实际 Token 下降 `57.7%`。

本报告只评价检索、Deep Read、证据接纳和 Requirement 覆盖。运行设置了 `answerGenerationSkipped=true`，不评价最终自然语言答案；完整回答与引用另见 [Fast / Deep 五题对照](fast-vs-deep-full-answer.md)。

## 剩余问题

8 题 Recall@5 低于 1：3 题未命中，5 题部分命中，其中 2 题在 Top-10 恢复完整召回。

1. 极低信息查询仍是第一瓶颈。只有模糊章节词时，正确文档可能不进入候选池，父块 Deep Read 无法补救上游未召回内容。
2. Ant Design 的口语化、迁移式章节标题最难恢复，来源 Recall@5 为 `0.9300`。
3. 少量三 Goal 问题已召回全部正确文档，但 Top-5 的 Goal 配额或同文档竞争仍会挤掉一个目标。

后续优化应单独扩充低信息查询回归集，重点观察标题实体恢复和 Top-5 Goal 平衡，不应通过手写项目词映射或缩小父块候选池来换取表面 Token 下降。

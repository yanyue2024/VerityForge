# Contributing

VerityForge is maintained as a curated, source-available portfolio project rather than an open-source community distribution. Reproducible defect reports, documentation corrections, and evaluation-method questions are welcome through GitHub Issues or Discussions.

Before opening an issue:

- Check the latest public snapshot and include the affected component and version.
- Use synthetic data and remove credentials, private URLs, document content, and personal information.
- Provide the smallest useful reproduction and distinguish observed behavior from the expected result.
- Report security concerns privately according to [SECURITY.md](SECURITY.md), not in a public issue.

Please discuss substantial code changes with the maintainer before opening a pull request. Unsolicited feature pull requests may be declined to preserve the project's product and licensing direction. Any accepted contribution must be the contributor's original work and will be distributed under the repository's current license unless a separate written agreement applies.
